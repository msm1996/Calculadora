# 🧮 Calculadora

Aplicação Front-End desenvolvida com **HTML5, CSS3 e JavaScript** para realizar operações matemáticas básicas através de uma interface simples e interativa.

O projeto foi desenvolvido para praticar conceitos fundamentais de JavaScript, como lógica de programação, eventos, funções e manipulação dinâmica do DOM.

## 🚀 Sobre o projeto

A **Calculadora** foi desenvolvida como um projeto de estudo para colocar em prática conceitos fundamentais do desenvolvimento Front-End.

O usuário pode inserir valores através dos botões da interface e realizar operações matemáticas básicas.

O JavaScript é responsável por processar as operações e atualizar dinamicamente o resultado apresentado na tela.

## ⚙️ Como funciona

O funcionamento da aplicação segue um fluxo simples:

1. O usuário informa os valores através dos botões.
2. Seleciona a operação matemática desejada.
3. O JavaScript processa os valores.
4. O resultado da operação é calculado.
5. A interface é atualizada dinamicamente com o resultado.
